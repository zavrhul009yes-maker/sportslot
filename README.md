# SportSlot — система бронирования спортивных занятий

Информационная система для записи на спортивные занятия в учебном заведении.

## Назначение

Пользователь выбирает вид спорта, дату, время и тренера, создаёт запись, отслеживает её состояние, оценивает тренера после посещения. Администратор управляет всеми бронированиями и видит аналитику.

## Роли

### Пользователь
- Регистрация и вход
- Создание записи на занятие
- Просмотр своих записей
- Отмена активной записи
- Оценка тренера после посещения
- Фильтрация и поиск

### Администратор
- Просмотр всех записей
- Отметка «Посещено»
- Отмена любой записи
- Административная панель с аналитикой (6 показателей, 2 диаграммы)
- Фильтрация по периоду и виду спорта

## Новые функции (реализованные в этой работе)

1. **История изменения статусов** — таблица `status_history`, отображается в карточке записи
2. **Оценка тренеров** — таблица `reviews`, звёздный рейтинг после посещения
3. **Расширенный фильтр** — по виду спорта, статусу, с сортировкой
4. **Административная аналитика** — 6 показателей + 2 диаграммы Chart.js
5. **Бизнес-правило** — запрет пересечения по времени у одного тренера

## Технологии

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** Supabase (PostgreSQL + Auth + RLS)
- **Библиотеки:** `@supabase/supabase-js`, `Chart.js`
- **Хранение секретов:** `.env` (не публикуется)
